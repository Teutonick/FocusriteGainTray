FocGrain — независимый проект сообщества для управления gain через MIDI.
Не является продуктом Focusrite и не одобрен компанией.

Перед копированием FocGrain мастер проверит Windows, Visual C++ x64,
Windows MIDI Services, Virtual Device App Transport, Focusrite Control 2
и регистрацию пакета драйверов Focusrite. .NET включён в приложение.

Недостающие Visual C++ и FC2 можно загрузить с официальных сайтов
и установить прямо из шага подготовки. Загрузка и запуск требуют
отдельного согласия. FC2 устанавливается с собственным интерфейсом,
лицензией и драйвером; это может временно прервать работу аудиопрограмм.

Системная MIDI-служба и Virtual Device App Transport поставляются через
Windows Update. Если они недоступны, мастер предложит открыть обновления
Windows и повторить проверку. Программа не меняет системный MIDI-режим
и не устанавливает посторонние MIDI-драйверы.

Приложение использует Windows MIDI Services API Preview 11. Компоненты
Preview могут потребовать обновления. Сохраняйте setup новой версии:
повторная установка с тем же идентификатором обновляет приложение,
а деинсталляция удаляет его app-local Preview API.

Физический gain не считывается. Успешная проверка компонентов не означает,
что интерфейс поддерживает MIDI gain или что FC2 уже настроен.
После запуска выберите FocGrain в настройках MIDI Control в FC2.
Минимальный gain не является mute. ПО предоставляется «как есть».
