# Contributing

Read AGENTS.md, docs/PROJECT.md and docs/TESTING.md first. Describe the user problem, keep the patch focused, add meaningful regression cases for behavior changes and report exact validation commands/results. Do not replace official MIDI control with private device protocols or Windows microphone volume.

Submit only code/assets you may license under MIT. Contributions are offered under this project's MIT license; preserve attribution for third-party material and document dependencies. Do not add vendor logos, copied screenshots or SDK binaries without permission and redistribution review. AI-generated changes require the same human review and evidence as other changes.

Never include user logs, credentials or local settings in changes. For a suspected security issue, avoid publishing sensitive data in a public issue. This project currently offers no private security-report channel or response-time guarantee.
